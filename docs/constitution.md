# GoSync Constitution

1. Use Go and the standard library unless a dependency is justified.
2. Keep the CLI free of graphical interfaces and web services.
3. Propagate and handle every I/O, network, and configuration error.
4. Keep functions small, deterministic, and named in English.
5. Add or update tests for every modifiable behavior.
6. Run `go test` successfully before integrating changes.
7. Do not modify `specs/` or user data without explicit authorization.
